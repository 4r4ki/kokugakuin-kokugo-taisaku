# 國學院栃木 国語 対策

國學院大學栃木中学校の入試問題（国語 大問1・大問3）の対策用Webアプリです。

## 使い方

`index.html` をブラウザで開くだけで使えます。

- **大問1 知識問題**：本番と同じ12問のテスト、または分野べつの練習
- **大問3 詩・短歌**：本番形式テスト（第1回形式の詩2セット・第2回形式の短歌・俳句2セット）と、作品べつの練習
- **過去問**：`data/kakomon/kakomon.js` があるときだけ表示されます
- **まちがえた問題の復習**：最後にまちがえた問題だけを解き直せます
- **知識を学ぶ**：17のテーマ（漢字・部首・敬語・表現技法・季語など）のまとめと暗記カード。テーマごとの練習問題にも進めます

スマホでは https://4r4ki.github.io/kokugakuin-kokugo-taisaku/ から使えます（過去問は入っていません）。

正答率などの記録は、使っている端末のブラウザの中にだけ保存されます。

## 出題傾向（2024〜2026年度 第1回・第2回より）

### 大問1（知識・12問前後）
毎回ほぼ同じ分野から1問ずつ出ます。

| 分野 | よく出る形 |
| --- | --- |
| 漢字 | 同訓異字の組み合わせ、送りがな・かなづかいの誤り、文中の誤字を抜き出して直す |
| 部首 | 共通する部首をつけて成り立たないもの、①〜④の説明すべてに合う漢字一字 |
| 画数・筆順 | 太字の部分は何画目か、総画数の正誤、画数順に並べる |
| 熟語 | 熟語の構成（「温泉」「登山」型など）、重箱読み・湯桶読み、二通りの読み方 |
| 四字熟語 | 〔A〕〔B〕に入る漢字、漢字表記と意味の正誤、数字を足す |
| 慣用句・ことわざ | 意味の正誤、正しい使い方、体の一部を入れる |
| 敬語 | 尊敬語・謙譲語の正誤（「うかがう」「めしあがる」「拝見する」が頻出） |
| 文法 | 主語と述語、文節の数、読点の位置、「そうだ」などの働き、自動詞・他動詞 |
| 言葉の知識 | カタカナ語、ものの数え方、国語辞典の順番、時候のあいさつ、類義語・対義語 |
| 文章 | 文の並べかえ、二文を一文に、報告文・感想文・話し合いの注意点 |

### 大問3（詩・短歌）
**第1回は詩、第2回は短歌・俳句**という分け方が3年続いています。

| | 第1回 | 第2回 |
| --- | --- | --- |
| 2026年度 | 詩（石垣りん） | 俳句6句 |
| 2025年度 | 詩（草野心平） | 俳句5句と鑑賞文 |
| 2024年度 | 詩（まど・みちお） | 短歌6首 |

- 詩：形式（口語自由詩など）は毎回出題。表現技法（直喩・擬人法・倒置法など）、品詞、——線部の意味、詩全体の説明を選ぶ問題
- 短歌・俳句：季節（季語）、句切れ・字余り・体言止め、鑑賞文の空らん補充、説明に合う作品を選ぶ問題

## データの追加

- オリジナル問題：`data/original.js`・`data/original-more.js`（大問1）、`data/original-d3.js`・`data/original-d3-more.js`（大問3）
- 大問3の本番形式テスト：`data/test-d3.js`（本文の `［①……］` は——線部①として線を引いて表示）
- 知識ページ：`data/learn.js`
- ファイルを変えたら、`index.html` の `?v=` の番号を上げてください（スマホに古いファイルが残らないようにするため）
- 過去問：`data/kakomon/kakomon.js`

問題の形式（`type`）は次の6つです：`choice`（一つ選ぶ）、`multi`（すべて選ぶ）、`order`（並べかえ）、`text`（書いて答える）、`parts`（小問がいくつかある）、`self`（模範解答を見て自分で丸をつける）。

## 注意

過去問の本文や写真は著作物です。`photos/` と `data/kakomon/` はGitにコミットされない設定にしてあります。GitHubに上げる場合も、非公開リポジトリにしてください。

大問3のオリジナル問題では、このアプリのために書いた詩と、著作権が切れた作家（若山牧水・与謝野晶子・石川啄木・正岡子規・斎藤茂吉・北原白秋・八木重吉・松尾芭蕉・与謝蕪村・小林一茶・種田山頭火・高浜虚子・金子みすゞ・山村暮鳥・高村光太郎・河東碧梧桐・尾崎放哉）の作品だけを使っています。
